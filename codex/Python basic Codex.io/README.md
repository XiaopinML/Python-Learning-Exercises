# Python Learning Exercises

This repository contains Python exercises from the courses I have followed at Codédex.io. Each exercise is organized into different categories and chapters.

## Directory Structure

- `1-hello-world/`: Basic Python programs to get started.
- `2-variables/`: Exercises on variables and basic arithmetic operations.
- `3-control-flow/`: Control flow exercises including conditionals and loops.
- `4-loops/`: More advanced loop exercises.
- `5-lists/`: Exercises on list operations.
- `6-functions/`: Function definitions and usage.
- `7-classes-objects/`: Object-oriented programming exercises.
- `8-modules/`: Working with Python modules.

## Exercises

### Hello World
- `02_hello_world.py`: Print "Hello world!".
- `03_pattern.py`: Print a number pattern.
- `04_initials.py`: Print initials in a pattern.
- `05_letter.py`: Print a formatted letter.

- `09_quadratic.py`: Solve a quadratic equation.
